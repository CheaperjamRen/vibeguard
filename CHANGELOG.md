# Changelog

## v1.1.0

Initial GitHub-ready release.

### Added

- Pre-coding brief workflow for AI Coding tasks.
- Tiny / Standard / Spec-level task handling.
- GO / GO WITH ASSUMPTIONS / NO-GO gate checks.
- Bugfix, refactor, prompt review, handoff, and release notes modes.
- Mini / Standard / Full Spec framework.
- Context layering: facts, assumptions, unknowns, and deprecated context.
- Acceptance contracts with verifiable checks.
- Coding guardrails for coupling, front-end/back-end boundaries, state ownership, global variables, naming, and maintainability.

### Notes

- This repository is the public GitHub version of VibeGuard.
- The skill content is kept prompt-native and tool-agnostic so it can be adapted to different Coding Agents.
