# How VibeGuard compares to GitHub Spec Kit

GitHub Spec Kit is a full Spec-Driven Development toolkit. It provides a CLI, agent integrations, slash commands, extensions, presets, and a structured workflow from specification to plan, tasks, and implementation.

VibeGuard is intentionally smaller.

It is not trying to replace Spec Kit. It is for people who want a lighter starting point before adopting a full spec-driven toolchain.

## The difference

| Area | GitHub Spec Kit | VibeGuard |
|---|---|---|
| Main form | CLI and agent integrations | Templates and small scripts |
| Workflow | Full spec-driven development process | Pre-coding brief and current-task context |
| Best for | Users ready to adopt a formal SDD workflow | Users who want a low-friction habit before AI coding |
| Automation | Higher | Lower |
| Setup | Requires toolchain setup | Can start by copying templates |
| Focus | Spec as the source for implementation | Requirement clarity before asking AI to code |

## When to use Spec Kit

Use Spec Kit if you want:

- a more complete Spec-Driven Development workflow
- CLI-based project setup
- multiple agent integrations
- extensions and presets
- a stronger path from spec to implementation

## When to use VibeGuard

Use VibeGuard if you want:

- a small habit before asking AI to code
- clearer product intent and boundaries
- a current-task brief instead of a long chat history
- a low-friction way to reduce repeated explanation and mid-task correction
- something lightweight before adopting a full SDD toolchain

In short: Spec Kit is a full toolkit. VibeGuard is a lightweight pre-coding brief.
